# Group Policy Management Lab

## Overview

This lab demonstrates how Group Policy Objects (GPOs) are used to manage users and computers in an Active Directory environment.

---

## Objectives

- Create Group Policy Objects
- Configure Password Policy
- Configure Account Lockout Policy
- Disable Control Panel
- Disable Task Manager
- Test GPO application

---

## Technologies Used

- Windows Server 2022
- Group Policy Management Console (GPMC)
- Active Directory

---

## Lab Tasks

### Password Policy

Configured:

- Minimum password length
- Password complexity
- Password expiration

### Account Lockout Policy

Configured:

- Lockout threshold
- Lockout duration

### Desktop Restrictions

Configured:

- Disable Control Panel
- Disable Task Manager

### Testing

Verified policy application on client machines.
